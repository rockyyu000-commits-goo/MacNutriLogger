# MacNutriLogger

Calorie/macro tracker (installable PWA) for McMaster: dining-hall menus plus nearby chain restaurants,
browsed as folders: favourites, on campus, chains, other nearby, with a search box. No dependencies; Node ≥ 20.

```
ADMIN_TOKEN=choose-a-secret npm start      # http://localhost:3000, admin at /admin.html
npm test
```

See [docs/WINDOWS.md](docs/WINDOWS.md) to run it 24/7 on a Windows laptop (auto-start, no sleep, private HTTPS via Tailscale).

## Getting data in
| Source | Command | Notes |
|---|---|---|
| McMaster dining halls (CSV) | `node scripts/import-csv.js file.csv` | Done: `data/seed/mcmaster_menu.csv` (1,463 items, 9 locations) auto-seeds an empty DB. Values are per serving; suspect rows (e.g. >2500 kcal) are flagged. |
| McMaster refresh | `node scripts/import-csv.js file.csv` | The built-in live scraper (`scripts/scrape-mcmaster.js`) does **not** work: macnutrition.mcmaster.ca (DevExpress) loads item nutrition via script callbacks. Re-run your own CSV export instead. |
| Nearby restaurants | `data/seed/nearby_restaurants.json` | 57 places (Main St W / King St W / Newton Ave) seeded as empty folders on first start. No nutrition yet. |
| Chain nutrition (official) | `data/seed/chains/*.json`, loaded automatically | Subway, Mr.Sub, Tim Hortons, Pita Pit, barBURRITO, Quesada, Sushi Shop, Pizza Nova, Williams Fresh Cafe. Each is generated by a script in `scripts/` (see below) and loaded once per chain on first start; later edits in the admin page are never overwritten. |
| Menu photos / anything else | `ADMIN_TOKEN=… node scripts/import.js menu.json` or paste into `/admin.html` | Send photos of menus; they're transcribed to JSON of the shape below. |

### Refreshing chain data
| Chain | Command | Source / notes |
|---|---|---|
| Subway | `pdftotext -layout CAN_Nutrition.pdf n.txt && python3 scripts/parse-subway-pdf.py n.txt` | Official PDF linked from subway.com/en-ca/menunutrition/nutrition. Footlongs are 2x the 6" values (per Subway's note). |
| Mr.Sub | `python3 scripts/parse-mrsub-pdf.py n.txt` | PDF June 2025 (mrsub.ca/nutrition). Small/Large/Kid's/Breakfast blocks are inferred from position in the PDF. |
| Tim Hortons | `python3 scripts/fetch-tims.py` | Public Sanity CMS behind timhortons.ca. Uses the as-served numbers (default toppings/milk included). |
| Pita Pit | `python3 scripts/parse-pitapit-pdf.py guide.pdf` | Aug 2026 guide (pitapit.ca/nutrition). Position-based parser; rows it can't name/verify are skipped or flagged `verify-name`. |
| barBURRITO | `python3 scripts/fetch-barburrito.py` | Component data from the site's calculator, scaled the way its JS does. Add components together for a full order. |
| Quesada / Sushi Shop | `python3 scripts/parse-layout-pdf.py quesada\|sushi-shop n.txt` | Official PDFs (Aug 2026 / 2026). |
| Pizza Nova | `python3 scripts/fetch-pizzanova.py` | Calories only, per slice. |
| Williams Fresh Cafe | `python3 scripts/fetch-williams.py cachedir` | One image-only Nutrition Facts PDF per item, read with OCR (rapidocr). OCR rows that fail a calories-vs-macros check are flagged. |

Not covered yet (no usable published nutrition found): Smoke's Poutinerie, Lava Pizza & Wings, Quik Chik, Chung Chun Rice Hotdog, Starbucks, and the independent restaurants.

```json
{ "locations": [{ "name": "Subway", "lat": 43.26, "lon": -79.92 }],
  "items": [{ "locationId": "subway", "name": "Turkey 6in", "category": "Subs", "serving": "6 in",
              "calories": 280, "protein": 18, "carbs": 46, "fat": 3.5, "source": "photo" }] }
```

Everything is editable later: `PUT/DELETE /api/admin/{locations,items}/:id`, `POST /api/admin/import` (Bearer `ADMIN_TOKEN`).
Item `source` (`mcmaster`, `chain`, `photo`, `manual`) tells you how trustworthy a number is.
Data lives in `data/db.json` (gitignored); the food log lives in the browser's localStorage.
